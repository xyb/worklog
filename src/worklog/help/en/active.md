---
title: active — what's timing right now
category: command
see_also: time, day, start
---
`wl active` lists tasks with an open clock (currently timing), each with its running elapsed,
today's total, and latest log — a quick "what am I on right now?".
  wl active
  wl active -q       # just id + elapsed
Close a forgotten timer with `wl stop <id>`. See `wl help time`.
